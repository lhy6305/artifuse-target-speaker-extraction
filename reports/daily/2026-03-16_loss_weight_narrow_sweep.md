# 2026-03-16 Loss Weight Narrow Sweep

## 本次目的

上一轮小扫描已经确认：

- `ref_film + stft0.5 + sisdr0.0005` 当前最优
- `stft_weight=0.6` 方向可以排除

因此本轮不再发散，只围绕当前最优点做更窄的 `sisdr_weight` 扫描，目标是确认：

- `0.0005` 是不是只是巧合点
- 还是这一区间里的真实局部最优

## 本轮扫描点

固定：

- 结构：`ref_film`
- `stft_weight`: `0.5`
- synthetic 分布：`2048 / 512 / default`
- epochs: `6`
- batch size: `16`

新增扫描：

1. `sisdr_weight=0.0003`
2. `sisdr_weight=0.0004`
3. `sisdr_weight=0.0006`

对照基线：

- `sisdr_weight=0.0005`

## 关键结论

### 1. `sisdr0005` 不是偶然点，而是当前窄区间内的明确最优点

`sisdr0005` 相对 `sisdr0004`：

- `loss`: `-0.000801`
- `waveform_l1`: `-0.000193`
- `stft_l1`: `-0.001216`
- `sisdr_db`: `+0.794458 dB`

也就是说：

- `0.0005` 直接支配 `0.0004`
- 不只是 `sisdr_db` 更好，重建类指标也更好

### 2. `sisdr_weight` 在当前模型上不是“越小越稳”，也不是“越大越强”

从 `0.0005` 往两边挪：

- 往低到 `0.0003`
  - `sisdr_db` 明显掉回 `-11.21 dB`
- 往高到 `0.0006`
  - 四项指标一起明显退化

说明：

- 当前最优点附近是比较尖的
- 不是一个很宽的平台

### 3. 当前主线应该收敛，不再继续在远离 `0.0005` 的点上浪费算力

这轮已经足够说明：

- `0.0003` 偏弱
- `0.0004` 可用但不如 `0.0005`
- `0.0006` 已经明显过头

所以当前继续在 `0.0002` 或 `0.0007+` 这些更远点上试探，信息密度不会高。

## 与 legacy stage2 的关系

当前最优点 `ref_film + stft0.5 + sisdr0.0005` 相对 legacy stage2：

- `loss`: `-0.000181`
- `waveform_l1`: `-0.000276`
- `stft_l1`: `+0.000190`
- `sisdr_db`: `+2.231390 dB`

这仍然是当前最有价值的结论。

大白话讲，就是：

- 相比老主线，这个新点几乎没有明显多付出重建代价
- 但分离主指标明显更强

## 当前结论

当前最佳候选主线继续保持为：

- `ref_film + stft0.5 + sisdr0.0005`

而且这次已经不是“粗扫里暂时最好”，而是经过窄范围确认后的稳定最优点。
